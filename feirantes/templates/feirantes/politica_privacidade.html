Política de Privacidade

No Sistema de Feirantes, valorizamos a privacidade dos usuários. Esta política explica como coletamos, usamos e protegemos seus dados pessoais.

1. Dados Coletados

Coletamos informações como nome, e-mail, CPF, telefone, endereço e fotos fornecidas no cadastro de feirante. Para consumidores, podemos coletar apenas dados de contato se houver interação com feirantes.

2. Uso dos Dados

Os dados são utilizados para: criar perfis de feirantes, exibir informações no site, comunicação entre feirantes e consumidores e envio de notificações relevantes.

3. Compartilhamento

Não compartilhamos dados pessoais com terceiros, exceto quando exigido por lei ou para prestação de serviços essenciais (como processamento de pagamento).

4. Direitos do Usuário (LGPD)

  • Confirmar a existência de tratamento de dados.
  • Acessar e corrigir dados pessoais.
  • Solicitar anonimização ou exclusão de dados.
  • Revogar consentimento a qualquer momento.

5. Segurança

Adotamos medidas técnicas e administrativas para proteger seus dados contra acesso não autorizado, perda ou alteração.

Para dúvidas ou solicitações sobre privacidade, entre em contato pelo e-mail: lucbam2@gmail.com.
